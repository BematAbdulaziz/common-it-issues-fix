# common-it-issues-fix
# ⚡ Common IT Issues & Fixes

## 🔍 Overview

Daily IT problems and quick solutions for faster troubleshooting.

---

## ❌ Issue: USB Not Detected

### 🔧 Fix:

1. Try different USB port
2. Open Device Manager
3. Update USB drivers
4. Restart system

---

## 🔊 Issue: No Sound

### 🔧 Fix:

1. Check volume settings
2. Right-click sound icon → Troubleshoot
3. Update audio driver
4. Check output device

---

## 🔑 Issue: Forgot Windows Password

### 🔧 Fix:

1. Use Safe Mode
2. Use password reset disk
3. Use recovery options

---

## 🔄 Issue: System Hanging

### 🔧 Fix:

1. End heavy tasks
2. Scan for malware
3. Check disk health
4. Upgrade RAM

---

## 🧠 Tip

Always start with software troubleshooting before hardware replacement.
